# CubeArc

Tools for transforming data and investigating local evidence.
Choose the product you want to use:

| Product | Start here |
| --- | --- |
| **Cube** | [Install the CLI](https://github.com/cubearc/cube/blob/main/docs/installation.md) or [run a first operation](https://github.com/cubearc/cube/blob/main/docs/getting-started.md). Use the same Rust engine from Python or Rust. |
| **Cube Play** | [Open an investigation](https://github.com/cubearc/play/blob/main/docs/getting-started.md) to browse files, use the visual Lab and retain findings in a local workspace. |
| **Recipes** | [Write a reusable workflow](https://github.com/cubearc/recipes/blob/main/docs/authoring.md) with explicit input, output and compatibility checks. |

Already using Cube? Find a [task guide](https://github.com/cubearc/cube/blob/main/docs/guides/index.md) or search for an
operation ID in the [operation reference](https://github.com/cubearc/cube/blob/main/docs/reference/operations.md).

These pages describe the [recorded source revisions](versions.md).
The getting-started instructions build from source.
