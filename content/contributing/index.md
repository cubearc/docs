# Contribute

Change documentation where its behavior is implemented:

- **Cube:** CLI, Python, Rust APIs and operation contracts.
- **Play:** local workspaces, Lab, terminal, notes and challenge progress.
- **Recipes:** reusable workflows, examples and compatibility fixtures.
- **Docs:** this portal, shared editorial policy and publication.

Use the [documentation guide](documentation.md) to choose the right page.
The [page patterns](templates.md) show the expected scope.
For build and publication changes, read [site maintenance](site.md).

Keep the code and affected documentation in the same product PR. The portal
adopts reviewed product commits through its version manifest.
